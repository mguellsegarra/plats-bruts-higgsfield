## Prepara la prova

1. Desa el [vídeo original](https://www.tiktok.com/@dany_stark1/video/7692922779645037845) i carrega el fitxer a **Motion Transfer** de Higgsfield.
2. Carrega les 8 imatges de la llista anterior i copia el [prompt](PROMPT.txt).
3. Genera una prova i revisa el resultat. Tens els passos complets a la [guia de Motion Transfer](../../docs/COM-FER-HO.md).

Revisa el perfil inicial del David i la continuïtat dels cabells quan aixeca el cap. Les alçades que apareixen al prompt són orientatives.
