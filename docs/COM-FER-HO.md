# Prepara una prova de vídeo

1. Tria un dels [projectes](../README.md#projectes) i obre la seva fitxa.
2. Mira el resultat publicat i el vídeo original de TikTok per veure quins moviments es transfereixen.
3. Desa el vídeo base i retalla'n uns segons amb el moviment que vulguis comprovar. A Higgsfield has de carregar aquest fitxer, no l'enllaç de TikTok.
4. A Higgsfield, selecciona Motion Transfer i carrega la base i els PNG enllaçats a la fitxa del projecte.
5. Enganxa el contingut de `PROMPT.txt` al camp del prompt. Si canvies de base, adapta les persones i els moviments descrits.
6. Revisa les opcions i el cost abans de generar una prova curta.
7. Mira la prova sencera. Comprova els girs de cap, la roba i els creuaments entre persones.
8. Si la prova et serveix, carrega el vídeo base complet, genera el resultat amb les mateixes imatges i el prompt, i revisa'l fins al final.
9. Comprova l'àudio i acaba el muntatge en un editor si cal.
